# Ducky Books, work showcase

Four pages describing accounting software I specified, directed and verified. It is in daily
use by a bookkeeping practice, which kept the books of 43 client businesses on it by September 2026.

**Live page:** https://duckyle1612.github.io/ducky-books-portfolio/

## What is in this repository

Only the pages and the demo video. **The product's source code is not here and will not be published.**

## About the video

Every screen in the video was captured from an isolated server running generated demo data, with
an invented company name and invented figures. No real client information, company name, tax
number or amount appears anywhere.

## About the numbers

The figures were counted on the running system in August and September 2026, most of them on
5 September. Six of them are shown with the database query behind them. The count of automated tests comes from the
product's code. Nothing is estimated or scaled up.
